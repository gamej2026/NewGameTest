## 1. 개요 (Overview)

### 1.1 제품 비전
‘혼’은 영혼·귀신이 아니라, 사람과 사람을 연결하고 기억·감정·이야기·문화를 이어주는 한국 고유의 정서다. 본 프로젝트는 이 정서를 **‘잇는다(연결)’는 행위**로 게임화하여, K-컬처의 감성을 3D 인터랙티브 경험으로 구현한다.

### 1.2 한 줄 콘셉트
> “끊어진 혼의 실을 다시 이어, 사람들이 미처 전하지 못한 마음을 완성한다.”

### 1.3 핵심 가치 제안
- **전투가 아닌 ‘연결’**을 핵심 동사로 삼는 차별화된 게임플레이.
- 한옥·청사초롱·도깨비불·정화수 등 **한국 전통 모티프의 3D 재해석**.
- 여름밤 **납량 분위기 + 끝내 따뜻한 정(情)**의 정서적 카타르시스.

### 1.4 문제 정의 / 기회
- K-컬처는 음악·영상 중심으로 주목받지만, **한국적 ‘정서’를 핵심 메커닉으로 삼은 게임**은 드물다.
- 게임잼이라는 짧은 제작 기간에 적합한, **작지만 완결성 높은 정서적 경험**으로 차별화 가능.

## 2. 목표 및 성공 지표 (Goals & Success Metrics)

### 2.1 제품 목표
1. ‘혼실 잇기’ 단일 메커닉으로 **5~10분 단일 경험**을 완결성 있게 구현한다.
2. 한국적 분위기를 3D 라이팅·사운드로 설득력 있게 전달한다.
3. 게임잼 발표에서 **‘정서적 임팩트’**로 심사·관객에게 각인된다.

### 2.2 최소 성공 기준 (MVP)
> 플레이어가 **인트로 → 게임씬(1개의 혼 만나기·사연 이해·혼실 잇기·정화) → 엔딩(크레딧)** 의 전체 흐름을 5~10분 안에 끊김 없이 체험할 수 있다.

### 2.3 성공 지표 (KPI)
| 지표 | 목표 |
| --- | --- |
| 전체 흐름 완주율 (인트로~엔딩) | 플레이테스터 90% 이상 |
| 게임씬 클리어 평균 시간 | 5~10분 |
| 분위기·정서 만족도 (5점) | 평균 4.0 이상 |
| 치명적 진행 불가 버그 | 발표 빌드 0건 |

### 2.4 비목표 (Non-Goals)
- 멀티플레이어, 온라인 기능.
- 전투/사망/리스폰 시스템.
- 다수 스테이지·오픈월드 또는 장시간 캠페인 (게임씬은 **단일 무대·단일 혼**).
- 풀 보이스 더빙, 대규모 컷신.
- 빛 색 전환·정화수 거울·삽사리 AI 등 보조 시스템(이번 범위 제외, 향후 확장).

## 4. 씬 구성 및 경험 흐름 (Scene Flow)

전체 경험은 **3개 씬**으로 선형 진행되며, 총 플레이타임은 5~10분이다.

```
[인트로 씬]  →  [게임씬]  →  [엔딩 씬 / 크레딧]
  ~1분          4~8분            ~1분
```

### 4.1 인트로 씬 (~1분)
분위기 설정과 최소한의 맥락 제시. 먹빛 화면에 마을·혼잡이 설정을 자막·나레이션·정적 이미지로 전달하고, 입력 시 게임씬으로 전환한다.

### 4.2 게임씬 (4~8분) — 핵심 루프
단일 무대(한옥 골목)에서 1개의 혼을 만나 아래 루프를 1회 완주한다.

```
탐험 → 혼 감지 → 기억 수집 → 혼실 잇기(퍼즐) → 정화
```

| 단계 | 플레이어 행동 | 시스템 반응 |
| --- | --- | --- |
| 1. 탐험 | 청사초롱으로 좌은 골목 탐색 | 빛이 닿는 범위만 또렷하게 렌더 |
| 2. 감지 | 주변 탐색 | 혼 근접 시 화면 ‘혼 떨림’ 이펙트 |
| 3. 기억 수집 | 유품(편지·사진·물건) 조사 | ‘혼의 사연’ 단서 노드 획득 |
| 4. 혼실 잇기 | 기억 노드를 인과·감정 순서로 연결 | 올바른 시퀀스 검증 → 이야기 재생 |
| 5. 정화 | 완성된 이야기 확인 | 혼이 도깨비불로 승천 → 엔딩 씬 전환 |

### 4.3 엔딩 씬 / 크레딧 (~1분)
혼을 배웅한 뒤 강가·백중 등불 연출로 정서적 마무리. 도깨비불이 하늘로 오르며 크레딧(제작자·감사 문구)이 올라가고, 끝나면 타이틀로 복귀한다.

## 7. 아트 & 사운드 요구사항

### 7.1 아트 디렉션
- **톤**: 먹빛 어둠 + 청록 도깨비불 + 금빛 한지. 저채도 배경 / 고채도 혼 빛으로 시선 유도.
- **환경 모티프**: 한옥, 기와, 청사초롱, 창호지 문, 장독대, 당산나무, 정화수, 한지 등불.
- **컬러 키**: 청록 `#7FD1D4`(혼·도깨비불), 금박 `#C8A96A`(기억·한지), 먹빛 `#0B0D12`(배경).

### 7.2 사운드
- 국악기(대금·해금·생황) 기반 BGM + 앰비언트.
- 매미·풍경(風磬)·물소리로 여름밤 공간감.
- 보이스 없이 **음향과 빛으로 감정 전달**(‘소리 기억’ 중심 서사).

## 10. 위험 요소 & 대응 (Risks & Mitigation)

| 위험 | 영향 | 대응 |
| --- | --- | --- |
| 혼실 잇기 퍼즐 난이도/직관성 부족 | 핵심 경험 손상 | 게임씬 도입부를 튜토리얼화, 시각적 힌트·오답 피드백 강화 |

| 공포 톤 과다 → 정서 전달 실패 | 테마 메시지 약화 | 공포 절정 직후 ‘따뜻한 정화’ 배치 규칙 준수 |
